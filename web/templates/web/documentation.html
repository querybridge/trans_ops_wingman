About This Prototype

Demo Documentation

What the prototype promises, how a manager uses it, what it connects to, and how well it performs on the evaluation set.

Product Promise

See which deliveries need attention, understand the evidence, and prepare the next action without searching several systems.

Primary user: a regional operations manager.

User Workflow

Three Workflows, One Screen

Today a manager reconciles a shipment export, dispatch notes, and a procedure folder to know what needs attention. The prototype brings those sources together on the Exceptions screen.

  1. 1

    Find Exceptions

    Choose a customer and region. The queue lists flagged shipments, highest severity first, with the rule, threshold, and age behind each flag.

    Counts and deadlines come from deterministic rules evaluated at the fixed demo timestamp, not from the AI.

  2. 2

    Explain a Shipment

    Open a shipment to see its facts, event timeline, dispatch notes, and the matching customer procedure. Request an explanation that cites those sources and proposes a next action and responsible role for review.

    Unknown or conflicting information is shown as such and flagged for verification.

  3. 3

    Create a Manager Briefing

    Generate a summary of the current filtered queue with counts, proposed actions, and links back to the source records.

    Recommendations are never sent or acted on automatically.

Exception Rules

How Shipments Are Flagged

Flags are calculated in code from shipment and scan records at the fixed demo timestamp. The AI never decides what is flagged or how many.

Scope

What It Does

  • Flags shipments with deterministic, documented rules evaluated at a fixed demo timestamp.
  • Shows the shipment facts, event timeline, dispatch notes, and matching procedures in one place.
  • Generates explanations and briefings that cite only the evidence shown, and states unknowns plainly.

Limitations

  • Synthetic data only; no real transportation management system is connected.
  • No predictive ETAs; ETAs are shown only when a source provides them.
  • No operational actions or automated communication; recommendations are for review.
  • Not production ready.
